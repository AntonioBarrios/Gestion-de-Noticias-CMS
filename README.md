# Gesti-n-de-Noticias-CMS-
Desarrolla el backend de un portal de noticias utilizando Arquitectura MVC y POO. Crea endpoints para crear, leer, actualizar y eliminar (CRUD) artículos, autores y categorías.
Este proyecto utiliza Laravel 11 (el framework más actual de PHP) e implementa la infraestructura solicitada a través de Docker.
